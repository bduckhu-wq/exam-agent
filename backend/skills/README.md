# Skills Directory

This directory contains Markdown Skill files that define the business logic for exam generation.

Each `.md` file is a self-contained Skill with YAML frontmatter for routing metadata and Markdown body for the system prompt.

## File Naming

- `*.md` files are automatically loaded as Skills
- `README.md` and files starting with `.` are ignored

## Skill Format

See `question-generator.md` for a complete example.
